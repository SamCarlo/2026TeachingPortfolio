# ELA 7–8 Scope & Sequence + Standards Coverage Map

Curriculum-planning artifacts for Grades 7–8 English Language Arts (2026–2027), plus a
vertical-alignment analysis against the Grades 5–6 "Lokahi" scope.

## Contents

| File | What it is |
|------|------------|
| `ela-7-8-scope-and-sequence.html` / `.pdf` | The full Grades 7–8 ELA scope & sequence: program model, year-at-a-glance for each grade, week-by-week quarter tables, and the Wilson Just Words word-study sequence. |
| `standards-coverage-map.html` / `.pdf` | A print-ready CCSS coverage matrix (strands × anchor standards 1–10) showing which standards are reached in both grade bands, in Grades 5–6 only, or in Grades 7–8 only, with continuity gaps flagged. |
| `standards-coverage-interactive.html` | The same matrix as a clickable web interface — click any chip to read that standard's full Common Core definition, cluster, and coverage status. Open in any browser. |

## The analysis in one line

Combining the Grades 5–6 (Lokahi) and Grades 7–8 (Carlos) scopes covers essentially the
full K–8 anchor set; the flagged **continuity gaps** — RI.5/7/8/9, RL.9, W.6/7/8, SL.2/3 —
are standards taught in 5–6 that the literature- and writing-craft-heavy 7–8 plan does not
explicitly carry forward.
